# 帝糖影展企劃網站

## 專案內容
- `index.html`：網站結構與企劃內容
- `css/style.css`：深紅、淺紅、米色視覺、Grid 與 RWD
- `js/main.js`：手機版導覽選單互動

## 部署
### GitHub Pages
1. 將此資料夾內所有檔案上傳至 GitHub repository 根目錄。
2. Repository → Settings → Pages。
3. Build and deployment 選擇 `Deploy from a branch`。
4. Branch 選 `main`、資料夾選 `/ (root)`，按 Save。
5. 等待完成後使用 Pages 提供的網址。

### Vercel
1. 將專案推送至 GitHub。
2. 登入 Vercel，選 Add New → Project，匯入此 repository。
3. Framework Preset 選 Other；Build Command 與 Output Directory 留空。
4. 按 Deploy。
